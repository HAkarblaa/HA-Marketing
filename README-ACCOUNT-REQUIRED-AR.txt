تحديث HA Marketing: الحساب إلزامي

استبدل الملفات المرفقة بنفس الأسماء والمسارات داخل الموقع، ثم ارفعها وأغلق التطبيق وافتحه مجدداً.
أضف الملف الجديد ha-account-gate.js بجانب index.html. احتفظ بمجلد css ومساراته كما في المضغوط.
لا يحتاج هذا التعديل تشغيل SQL أو تغيير الحسابات الموجودة.

المستخدم يدخل بحساب مسجل، أو ينشئ حساباً جديداً.
الدخول كضيف أو بعلامة ha_logged_in فقط غير متاح.
الحساب يبقى محفوظاً؛ لا يحتاج تسجيل دخول كل مرة ما دامت الجلسة صالحة.
فتح روابط الأقسام مباشرة يتطلب الحساب أيضاً.
بعد الدخول أو إنشاء الحساب يرجع المستخدم للصفحة التي حاول فتحها.
تسجيل الخروج يقفل صفحات التطبيق، حتى عند الرجوع أو في تبويب آخر.
بدون إنترنت لا يفتح التطبيق إلا بجلسة حساب محفوظة وغير منتهية.
الدخول والتسجيل واسترجاع الحساب وسياسة الخصوصية ومعلومات حذف الحساب متاحة للزائر.

الفحص محلي باستخدام جلسات اختبار؛ لم يتغير الموقع المنشور أو قاعدة البيانات.
بوابة الحساب تنظم دخول الواجهة؛ صلاحيات البيانات والأدوار تبقى حسب RLS والفحوص الموجودة في Supabase.
المضغوط يحتوي ملفات التعديل فقط، بدون الصور أو باقي الملفات غير المعدلة.
