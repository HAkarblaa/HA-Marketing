الأدمن الرئيسي يملك جميع الأقسام، والأدمن الفرعي تظهر له فقط الأقسام التي منحتها له.
هذا الحساب ليس لديه صلاحية دخول لوحة الإدارة.

إدارة أقسام التطبيق

هذه الصفحة تبين صلاحيات الحساب الحالي. الـSuper Admin يملك كل الأقسام تلقائياً. الأدمن الفرعي يملك الأقسام المحددة له فقط.

📚 تبليغ دراسي مستهدف

يظهر هذا الإرسال للـSuper Admin أو الأدمن الذي لديه صلاحية الدراسة. يمكن تحديد المحافظة والمرحلة والمدرسة والصف، ويصل فقط للطلاب المطابقين.

جاهز للإرسال.
ملاحظة: الإرسال المستهدف الفعلي المجهز حالياً هو للدراسة. بقية الأقسام تظهر ضمن صلاحيات الإدارة، ونضيف لكل قسم أدواته الحقيقية عندما يكون Backend الخاص به موجوداً، بدون إنشاء أزرار وهمية.

إضافة / تعديل أدمن

هذه الصفحة للـSuper Admin فقط. اكتب رقم الهاتف أو المعرّف لحساب موجود، ثم اختر الأقسام. يمكن تعيين أكثر من أدمن لنفس القسم.
