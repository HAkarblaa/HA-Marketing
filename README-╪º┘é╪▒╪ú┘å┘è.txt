قسم سوق المستخدمين — HA Marketing
=================================
هذا قسم HTML/CSS/JS مستقل متوافق مع موقع HA Marketing المبني من صفحات HTML.

التركيب السريع:
1. فك الضغط وانسخ الملفات التالية إلى جذر مستودع HA-Marketing بجانب index.html:
   marketplace.html
   marketplace.css
   marketplace.js
   marketplace-config.js
2. أضف مربعاً في الصفحة الرئيسية index.html، واجعل الرابط href="marketplace.html".
   مثال يمكن تعديله ليتناسب مع تصميم الصفحة:
   <a href="marketplace.html" class="section-card">🛍️ بيع وشراء</a>
3. ارفع الملفات إلى GitHub Pages، وافتح صفحة marketplace.html.

مهم جداً:
- الصفحة تشتغل فوراً في وضع تجريبي محلي وتعرض 3 إعلانات توضيحية.
- الإعلانات في وضع التجربة محفوظة على جهاز المتصفح فقط ولا يراها باقي المستخدمين.
- حتى يصير السوق حقيقي والكل يشوف الإعلانات:
  أ) استخدم مشروع Firebase الصحيح الخاص بك. في Firebase Console فعّل Authentication > Anonymous.
  ب) فعّل Realtime Database و Firebase Storage، وقد يتطلب Storage خطة مدفوعة.
  ج) أضف Firebase Web App واملأ معلوماته في marketplace-config.js داخل firebase:{...}.
  د) بدّل demoMode إلى false.
  هـ) أضف قواعد firebase-database-rules.json تحت مسار ha_marketplace إلى قواعد Realtime Database الحالية، ولا تستبدل القواعد الكاملة دون دمج.
  و) أضف قواعد firebase-storage-rules.txt إلى قواعد Storage الحالية مع الحفاظ على المسارات الأخرى.
- بيانات Firebase Web config ليست كلمة مرور سرية، لكن يجب تطبيق قواعد الأمان والتعامل مع الإساءة والسبام.
- الصور تضغط داخل المتصفح وترفع إلى Storage في الوضع الحقيقي.
- المفضلة تحفظ على جهاز المستخدم. لا توجد مدفوعات إلكترونية أو توصيل أو نظام طلبات مكتمل.
- زر التواصل يفتح واتساب مباشرة للرقم الذي ينشره البائع (ينبغي إعلام البائع أن رقمه سيكون متاحاً للمستخدمين).
- هذه نسخة أولية، قبل إطلاق عام ينبغي إضافة: مراجعة/تبليغ الإعلانات، حظر المنتجات الممنوعة، مكافحة السبام والاحتيال، سياسة خصوصية، تحقق من الهوية إذا تطلب، وحماية إساءة استخدام Firebase.
- إذا كانت سياسة التطبيق تتطلب حساباً حقيقياً، بدّل تسجيل Anonymous بنظام الحسابات الحالي قبل الإطلاق العام.
- ملفات JS تحتاج اتصالاً بالإنترنت لتحميل Firebase من CDN ولو في الوضع التجريبي؛ يمكن تحميل المكتبات محلياً إن أردت تشغيله بلا إنترنت.
