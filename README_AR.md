# برنامج إدارة المولدات — نسخة Supabase

1. شغّل `01_run_once.sql` مرة واحدة من Supabase SQL Editor.
2. انشر Edge Functions داخل مجلد `supabase/functions`:
   - `generator-login` بدون JWT verification.
   - `generator-admin-users` مع JWT verification.
3. ارفع `index.html` مكان ملف الموقع على GitHub Pages.

الموقع يحتوي مسبقاً على Project URL والـ Publishable Key فقط. لا يوجد أي Secret/Service Role داخل الموقع.
