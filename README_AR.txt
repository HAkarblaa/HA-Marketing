تعديل Offline + Sync

ارفع الملفين إلى جذر Repository generator-manager:
1) index.html
2) sw.js

العمل:
- أول تسجيل دخول يحتاج إنترنت.
- بعد أول تحميل، بيانات المولدة تنحفظ محلياً على الجهاز.
- عند انقطاع الإنترنت، الإضافة والتعديل والحذف تستمر محلياً.
- عند رجوع الإنترنت، تتم مزامنة آخر نسخة تلقائياً مع Supabase.
- تسجيل جهاز جديد/تغيير الحسابات/موافقات الأدمن تحتاج إنترنت.

ملاحظة: إذا تم تعديل نفس المولدة من جهازين وهما أوفلاين بنفس الوقت، آخر جهاز يعمل مزامنة هو الذي يحسم آخر نسخة.
