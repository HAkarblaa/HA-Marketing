HA Marketing - خريطة قلعة سكر تعمل بدون إنترنت

العمل:
- عند أول فتح لأي صفحة نقل والإنترنت موجود، يبدأ تنزيل خريطة قلعة سكر تلقائياً.
- تظهر رسالة صغيرة: جاري تجهيز خريطة قلعة سكر للعمل بدون إنترنت.
- بعد اكتمالها تظهر: تم حفظ خريطة قلعة سكر للعمل بدون إنترنت.
- بعد ذلك، بلاطات الخريطة المحفوظة تفتح حتى إذا انقطع الإنترنت.
- أي بلاطة يشاهدها المستخدم أثناء الاستخدام تُحفظ أيضاً تلقائياً.

مهم:
- التحميل التلقائي يحتاج إنترنت مرة واحدة فقط.
- هذا التعديل يحفظ صورة/شوارع الخريطة.
- البحث عن أسماء الأماكن وحساب المسار عبر الإنترنت يبقيان بحاجة للإنترنت،
  لأنهما خدمات خارجية منفصلة عن صورة الخريطة.
- لا يوجد تغيير على قاعدة البيانات أو الإشعارات أو الأسعار.
