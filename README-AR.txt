HA Marketing - تصغير واجهة السائق + إضافة الرصيد داخل نافذة

استبدل فقط:
driver.html

التعديل:
- تصغير عناصر واجهة السائق حتى تدخل بشكل أفضل ضمن عرض الشاشة.
- تصغير الخريطة والملخص وبطاقة الطلب.
- توصيل المتاجر صار مربع صغير عائم.
- حقل الرصيد صار صغير وفيه علامة +.
- عند الضغط على + تظهر نافذة "إضافة رصيد".
- المستخدم يكتب الكود داخل النافذة ويضغط "إضافة الرصيد".
- توجد علامة X داخل النافذة للخروج بدون إضافة.
- يمكن الضغط خارج النافذة أو زر Escape للخروج أيضاً.
- نظام الرصيد نفسه لم يتغير، ويستخدم redeem_balance_recharge_code.
- لم يتم تغيير منطق الطلبات أو الخرائط أو الإشعارات.
