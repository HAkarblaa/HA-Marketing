استبدل فقط:
driver.html

التعديل واجهة فقط ولم يتم تغيير منطق الطلبات أو الخرائط أو الإشعارات.

أهم التغييرات:
- أعلى الصفحة صار مختصر: اسم السائق + متصل/غير متصل فقط.
- معلومات المركبة التفصيلية مخفية من الواجهة لكن بقيت موجودة للكود.
- الرصيد صار أصغر.
- الخريطة صارت العنصر الرئيسي.
- 3 مربعات صغيرة: الطلبات، المسافة، السعر.
- الطلب القريب يعرض فقط الانطلاق والوصول قبل القبول.
- أخفينا الهاتف والمدة الإضافية قبل قبول الطلب.
- أزرار قبول وتخطي فقط بشكل واضح.
- بعد القبول تبقى الاتصال والرسائل وحالة الرحلة والأزرار الأساسية.
- الوضع النهاري والليلي يبقون شغالين.
- تنبيه تفعيل الموقع ودائرة البحث يبقون شغالين.
