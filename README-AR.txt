تعديل شريط "تسوق الآن" إلى شريط أخبار متحرك

استبدل / ارفع فقط:
- index.html
- index-offline.html
- admin-home-ticker.html
- HA-HOME-NEWS-TICKER.sql

التركيب:
1) شغّل HA-HOME-NEWS-TICKER.sql في Supabase > SQL Editor مرة واحدة.
2) ارفع ملفات HTML الثلاثة إلى مجلد الموقع.
3) الأدمن الرئيسي يفتح admin-home-ticker.html وينشر الأخبار.
4) من حساب الأدمن الرئيسي يظهر رمز ✎ صغير داخل شريط الأخبار للدخول إلى صفحة الإدارة.
5) باقي المستخدمين يشوفون الأخبار فقط، والنص يتحرك داخل الشريط تلقائياً.

مهم:
- مربع "تسوق الآن" في الأقسام يبقى كما هو.
- فقط الشريط العلوي الذي كان مكتوباً فيه "تسوق الآن" تحول إلى أخبار متحركة.
- النشر والحذف والإخفاء للأدمن الرئيسي فقط.
