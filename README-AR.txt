HA Marketing - توجيه طلبات النقل حسب نوع السائق

التوجيه الجديد:
1) طلب تكسي -> يظهر فقط لسائق تكسي مسجل.
2) طلب تكتك -> يظهر فقط لسائق تكتك مسجل.
3) طلب مندوب:
   - مندوب -> يظهر للمندوب المسجل.
   - تكتك توصيل -> يظهر لسائق التكتك.
   - سيارة توصيل -> يظهر لسائق التكسي/السيارة.
