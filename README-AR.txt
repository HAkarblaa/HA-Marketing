إضافة المايك والإيموجيات لغرف الأونلاين — HA Marketing

تشمل: إكس أو، الدامة، الدومينو والشطرنج. تظهر داخل غرف اللاعبين فقط، وليس التدريب ضد الجهاز. لا تغيّر قواعد اللعب أو التصنيف أو الإعلانات.

التركيب:
1. خذ نسخة احتياطية. ارفع ملفات HTML وJS وCSS وservice-worker.js وha-entertainment-offline-manifest.json الموجودة بالحزمة إلى جذر الموقع واستبدل نظائرها.
2. شغّل RUN-GAME-COMMS.sql مرة واحدة في SQL Editor في مشروع Supabase الرئيسي. هذا ملف إعداد قاعدة البيانات، لا يكفي رفعه للموقع. يلزم أن تكون غرف الألعاب الأصلية موجودة وأن يكون أونلاين الألعاب مفعلاً مسبقاً، بما فيه Edge Function الخاص بالشطرنج.
3. أعد فتح التطبيق. افتح نفس الغرفة من جهازين، أرسل إيموجي ثم اضغط تشغيل المحادثة في كلا الجهازين واسمح بالمايك. بعدها الزر يكتم ويشغّل؛ زر إنهاء الصوت يوقف الميكروفون. الخروج أو انتقال الصفحة للخلفية يوقف الصوت، وتعيد تشغيله بنفسك عند الرجوع.
4. لا يحتاج الإيموجي إذن المايك. لا يوجد تسجيل للصوت؛ رسائل الربط مؤقتة وتُحذف بعد دقيقتين عند طلب التواصل التالي. الخادم يتحقق من عضوية الغرفة ويحد معدل الإرسال.

متطلبات الصوت المهمة:
- الموقع HTTPS ومتصفح/WebView يدعم WebRTC وإذن المايك.
- إذا تطبيق Android لا يحتوي RECORD_AUDIO وطلب الإذن وقت التشغيل ومعالجة WebChromeClient.onPermissionRequest للـ RESOURCE_AUDIO_CAPTURE على نطاق موقعك الموثوق فقط، لا يستطيع تعديل الموقع إضافة هذه الصلاحيات. حينها يلزم تعديل وبناء التطبيق. هذه الحزمة لا تتضمن تعديل Android ولم يتم فحص نسختك المثبتة.
- الربط الافتراضي يستخدم STUN. بعض شبكات الموبايل والجدران النارية تحتاج TURN؛ لا نضمن وصول الصوت بينها قبل إعداد TURN. يدعم الكود window.HAGameVoiceConfig.iceServers، يضبط قبل تشغيل الصوت بقائمة RTCIceServer. بيانات TURN تكون قصيرة الصلاحية من خادم موثوق، ولا تضع كلمة مرور دائمة أو مفتاح خدمة في الموقع. لا توجد خدمة TURN مدفوعة أو بياناتها ضمن هذه الحزمة.
- الصوت يحتاج الإنترنت، وليس جزءاً من اللعب أوفلاين. لا يضيف نقاطاً أو يعيد إرسال نتائج الأوفلاين.

الفحص: اختبار محلي لتبادل عرض/قبول WebRTC بين متصفحين بميكروفونات اختبار، والتحقق من الإيموجيات والكتم والإغلاق وصلاحيات قاعدة البيانات. لم تُنشر إعدادات الخادم في حسابك ولم يُتحقق من وصول الصوت فعلياً عبر الشبكة، ولا على هواتفك أو شبكاتها.
