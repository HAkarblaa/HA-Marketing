# إدارة المولدة — نظام الأدمن الرئيسي والحسابات

- الحساب الموجود سابقاً على نفس المتصفح يتم ترقيته تلقائياً إلى أدمن رئيسي.
- لا يوجد إنشاء حساب للمستخدمين من صفحة الدخول.
- الأدمن الرئيسي ينشئ حسابات أصحاب المولدات من قسم إدارة الحسابات.
- يمكن للأدمن تفعيل/إيقاف الحساب وتغيير كلمة المرور وحذف الحساب.

مهم: هذه النسخة تستخدم localStorage، لذلك الحسابات التي ينشئها الأدمن محفوظة في نفس المتصفح فقط. لكي تعمل الحسابات من أجهزة مختلفة يجب ربط الموقع بقاعدة بيانات أونلاين مثل Supabase أو Firebase.
