تعديل تصميم صفحة طلب الخدمة فقط

استبدل ملف:
services.html

المهم:
- لم يتم تغيير JavaScript أو قاعدة البيانات أو روابط الوظائف.
- التغيير شكلي فقط.
- ترتيب واجهة خدمات العملاء أصبح مثل التصميم المختار.
- قسم مقدم الخدمة أصبح بشكل 4 بطاقات مثل الصورة.
- الأقسام والبحث والخدمات الموجودة سابقاً ما زالت موجودة تحت الصفحة.
- خيارات مقدم الخدمة المعتمد الخاصة تبقى تعمل بنفس التحقق السابق.
