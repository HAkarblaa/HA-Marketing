تصحيح آمن لإظهار الأقسام حسب نوع الحساب

هذه النسخة أُعيدت من ملف الموقع الأصلي hh(4).zip حتى لا يتأثر زر "متابعة الدخول".

استبدل فقط:
- index.html
- index-offline.html

النتيجة:
- الأدمن الرئيسي وباقي الأدمنية: تظهر كل الأقسام.
- المستخدم العادي: في الواجهة الرئيسية وقائمة الاختصارات تظهر الأقسام المطلوبة فقط:
  تسوق الآن، طلب خدمة، دراسة، طلب تكسي أو مندوب.
- لم يتم تعديل دالة "متابعة الدخول" نهائياً.
- تم فحص JavaScript في الملفين للتأكد من عدم وجود خطأ صياغة.
