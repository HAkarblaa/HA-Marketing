تحديث HA Marketing - الدردشة والمحتوى

1) شغّل الملف COMMUNITY-CONTENT-UPDATE.sql مرة واحدة داخل Supabase SQL Editor.
2) ارفع كل ملفات الموقع الجديدة مكان القديمة.
3) الدردشة الجديدة تعتمد اسم المستخدم من profiles ولا تسمح بكتابة اسم وهمي.
4) الدردشة: خاص + كروبات + بحث عن الأشخاص والمحادثات + قائمة آخر المحادثات + قراءة الرسائل لحظياً.
5) الأخبار: بحث + تصنيفات + عاجل + مميز + مصدر + لوحة إضافة وحذف من admin-content.html.
6) الديني: واجهة بحث ووصول سريع + آخر قسم تمت زيارته مع الحفاظ على كل الصفحات الدينية القديمة.
7) الترفيه: مركز موحد للألعاب والأدوات والاختبارات الموجودة.
8) الرياضة: أخبار كرة القدم + كرة القدم + الجم + لعبة الجزاءات + حاسبة BMI.
