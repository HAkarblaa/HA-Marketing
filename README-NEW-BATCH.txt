HA Marketing - الدفعة المجمعة

الموجود فعلياً في هذه النسخة:
- نظام الحسابات الحالي.
- طلب الخدمة الحقيقي في Supabase.
- قبول الموظف وتغيير حالة الطلب.
- مشاركة موقع الموظف وتتبع العميل.
- الإلغاء والتقييم.
- إشعارات داخل التطبيق Real-time محفوظة في Supabase.
- صفحة مركز الإشعارات notifications-center.html.
- لوحة إدارة admin.html للموافقة/رفض الموظفين ومراجعة الطلبات.

قاعدة البيانات:
1) SERVICE-ORDERS-SETUP.sql سبق تشغيله عند إعداد الطلبات.
2) شغّل ALL-BACKEND-UPDATE.sql مرة واحدة لإضافة الإشعارات ولوحة الإدارة.

مهم:
- Web Push الخارجي (إشعار يصل والجهاز مغلق) يحتاج إعداد Firebase/FCM خادمي ومفاتيح، لذلك هذه النسخة تعتمد على إشعارات داخل التطبيق الحقيقية وليست Push مزيفة.
- لتفعيل لوحة الإدارة يجب أن يكون account_type للحساب الإداري = admin في profiles. لا يتم تحويل أي مستخدم إلى Admin تلقائياً لأسباب أمنية.
- الدفع الإلكتروني وSMS/WhatsApp وخرائط التوجيه التجارية تحتاج مزودي خدمات خارجيين ولم يتم ادعاء أنها مفعلة في هذه الدفعة.
