HA Marketing - ملفات التعديل فقط

استبدل/أضف هذه الملفات داخل مجلد الموقع HA:
1) taxi.html
2) tuktuk.html
3) delivery.html
4) driver.html
5) transport-push.js  (ملف جديد)

ثم افتح Supabase > SQL Editor وشغّل:
6) TRANSPORT-AUTO-PUSH-SETUP.sql

التعديلات:
- طلب التكسي/التكتك/التوصيل يحفظ Supabase user id + Firebase uid.
- توجيه الطلبات حسب نوع السائق: تكسي / تكتك / مندوب.
- إشعار تلقائي للسائق عند الطلب الجديد.
- إشعار تلقائي للزبون عند القبول / الوصول / بدء الرحلة / الإنهاء / الرفض / إلغاء السائق.
- إشعار للسائق إذا الزبون ألغى الطلب بعد القبول.
- يستخدم send-fcm-push الموجود عندك؛ إذا database trigger أرسل أولاً، الدالة تتجاوز التكرار.
