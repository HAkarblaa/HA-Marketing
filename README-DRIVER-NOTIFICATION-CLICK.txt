تعديل الضغط على إشعار السائق — ملفات التعديل فقط

أضف ha-notification-route.js واستبدل بقية الملفات في جذر الموقع، ثم حدّث صفحة السائق مرة واحدة بعد اكتمال نشر GitHub Pages.
ما يحتاج تشغيل SQL أو استبدال Edge Function.

إشعارات التكسي والتكتك والدلفري تفتح driver.html مباشرة، ومعها رقم الرحلة إذا موجود في الإشعار.
إشعارات مندوب المتجر تفتح shop-courier.html مع رقم التوصيل إذا موجود.
الضغط على إشعار السائق داخل قائمة الإشعارات يتجاوز نافذة التفاصيل ويفتح واجهته مباشرة.

التحقق محلي لمسارات الروابط والضغط في المتصفح. لم يُختبر الضغط على جهاز المستخدم.
هذه الملفات تعدّل إشعارات الويب. إذا كان إشعار التطبيق يُنشأ بكود Android مستقل ويفتح الرئيسية فقط، نحتاج ملفات مشروع Android لتعديل وجهة الضغط فيه.
